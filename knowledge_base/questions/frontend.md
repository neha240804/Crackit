# Frontend development interview questions

## JavaScript fundamentals
Easy: Explain closures with an example.
Easy: What is the difference between var, let and const?
Intermediate: How does the event loop handle promises versus setTimeout?
Good answers cover: lexical scope, hoisting and temporal dead zone, microtask vs macrotask queues.

## React
Easy: What are props and state? What triggers a re-render?
Intermediate: When would you use useMemo or useCallback, and when are they unnecessary?
Intermediate: How do you manage server data versus UI state in a React app?
Good answers cover: unidirectional data flow, reconciliation and keys, effect dependencies, avoiding derived state, data-fetching libraries and caching.

## Performance and accessibility
Hard: A page feels slow. How do you find and fix the problem?
Intermediate: How do you make a custom component accessible?
Good answers cover: Lighthouse and performance profiler, code-splitting, image optimisation, memoisation; semantic HTML, keyboard navigation, ARIA only when needed, colour contrast.

## CSS and layout
Easy: Explain flexbox versus grid and when to use each.
Good answers cover: one-dimensional vs two-dimensional layout, responsive design, the box model.

## TypeScript
Intermediate: What benefits does TypeScript bring to a large frontend codebase?
Good answers cover: catching errors at compile time, typed API contracts, generics, union types and narrowing.
